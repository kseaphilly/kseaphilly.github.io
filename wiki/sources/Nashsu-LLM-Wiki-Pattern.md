# Nashsu LLM-Wiki: Semantic Synthesis & Knowledge Graphs

*Ref: https://github.com/nashsu/llm_wiki*

## High-Level Concept
A technical extension of the LLM-Wiki pattern focusing on **Semantic Rigor** and **Topological Organization**. It treats the wiki as a "Knowledge Graph" and uses graph theory and vector search to ensure deep connectivity.

## Key Innovations

### 1. Two-Step Ingest Pipeline
To avoid "Thin Summaries," Nashsu implements a mandatory two-phase process:
- **Phase 1: Analysis**: The LLM reads the source and outputs a JSON of *Claims*, *Entities*, and *Arguments*. No wiki files are written yet.
- **Phase 2: Synthesis**: The LLM compares the new JSON against the *existing* wiki index and produces a set of `multi_replace` patches to integrate the new info seamlessly into existing nodes.

### 2. Topological Connectivity
The framework uses specific metrics to determine if a link should exist:
- **Direct Link Connectivity**: Traditional [[wikilinks]].
- **Adamic-Adar Index**: Measuring the strength of connection between two topics based on shared concepts.
- **Type Affinity**: Ensuring similar entity types (e.g., "Protein" and "Drug") are cross-referenced according to a predefined ontology.

### 3. Vector-Mediated Retrieval
While Karpathy relies on `index.md`, Nashsu uses **LanceDB** to store embeddings of all wiki chunks:
- Allows for semantic "Vibe Search" (e.g., "Show me everything related to metabolic aging" even if those exact words aren't in the index).
- Combined with BM25 (Keyword search) for a "Hybrid" retrieval model.

### 4. Interactive GUI (Tauri)
Unlike purely terminal-based wikis, it provides a specialized UI:
- **Graph Viewer**: Real-time rendering of the knowledge clusters using Louvain Community Detection.
- **Preview Pane**: WYSIWYG editing with immediate rendering of citations and cross-links.

## Project Structure
```
src/             # Tauri/Rust backend for vector search
extension/       # Chrome extension for clipping sources
wiki/
├── clusters/    # Automatically grouped entity nodes
├── concepts/    # High-level theoretical nodes
├── graph.jsonld # Machine-readable semantic graph
└── index.md     # Auto-generated by Community Detection
```

## Philosophy
**Structural Insight.** The goal is not just to store data, but to discover *emergent patterns* across disparate sources using the LLM's analytical power.
