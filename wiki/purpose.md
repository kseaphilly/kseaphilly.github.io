# Purpose of KSEA Philadelphia Wiki

## Core Objective
The objective of this wiki is to maintain a persistent, LLM-readable, and human-browsable knowledge base for the KSEA Philadelphia Chapter website and operations. It serves as the long-term memory for design decisions, codebase architecture, and chapter history.

## Goals
1.  **Codebase Integrity**: Document the "Bio × AI" design system (v2) to ensure future updates maintain visual consistency.
2.  **Operational Continuity**: Keep track of leadership transitions, event history (NMSC, NRC), and sponsor relations.
3.  **Automation**: Provide a structured schema that allows AI agents to contribute to the website (ingesting new events, updating leaders) without human oversight.

## Scope
-   **Design**: CSS tokens, grid systems, and image dimension rules.
-   **Content**: Events, Leadership profiles, Sponsor details.
-   **Scripts**: Python automation tools used for migration and maintenance.
